# 📖 About The Project

NagarSetu is a digital civic engagement platform designed to bridge the communication gap between citizens and local authorities.

The platform provides a structured complaint lifecycle where citizens can report issues, administrators validate and assign complaints, and department officers update progress until resolution.

The goal is to improve transparency, accountability, and response efficiency in public issue management.

---

# ✨ Core Features

## 👤 Citizen Portal

* Register and login securely
* Report civic issues with descriptions and evidence
* Track complaint status in real time
* Access complete complaint history
* Receive progress updates

---

## 🛡️ Admin Dashboard

* Verify submitted complaints
* Assign complaints to departments
* Monitor resolution progress
* Manage officers and users
* Access complaint analytics

---

## 👨‍💼 Officer Dashboard

* View assigned issues
* Update work progress
* Upload completion proof
* Resolve complaints efficiently
* Maintain resolution records

# 🚀 Running Locally

## 1. Clone Repository

```bash id="eudjjo"
git clone https://github.com/yash-kumawat-0/nagarsetu.git
cd nagarsetu
```

---

## 2. Install Frontend Dependencies

```bash id="l6lzkv"
cd client
npm install
```

---

## 3. Install Backend Dependencies

```bash id="4oifh7"
cd ../server
npm install
```

---

## 4. Configure Environment Variables

Create a `.env` file inside the server directory.

```env id="oxc3cz"
PORT=5000

MONGO_URI=your_mongodb_connection_string

JWT_SECRET=your_jwt_secret
```

---

## 5. Start Backend Server

```bash id="vtef6e"
cd server
npm run dev
```

---

## 6. Start Frontend Application

```bash id="8f2owz"
cd client
npm run dev
```

---

## 7. Open In Browser

```text id="zlp67s"
http://localhost:5173
```
